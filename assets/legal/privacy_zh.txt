Centli（厘记）隐私政策

生效日期：2026-10-14

一、引言
Centli（厘记）是一款本地记账工具，口号是「厘清每一笔账单」。本政策说明我们如何处理与应用相关的信息。使用本应用即表示您已阅读并理解本政策。

二、我们收集的信息
- 应用不提供账号注册，也不要求登录。
- 账本、账户、分类、账单、待确认记录、商户规则、汇率缓存与应用设置等数据，仅保存在您设备上的本地数据库中。
- 首版不包含云同步、远程备份或服务器上传。

三、通知监听（可选，主要适用于 Android）
- 仅在您主动开启「自动记账」并授予系统「通知使用权」后生效。
- 目的：读取支付成功类通知，生成「待确认」账单草稿，辅助记账。
- 当前默认监听的应用包名范围：
  · 支付宝：com.eg.android.AlipayGphone
  · 微信：com.tencent.mm
- 默认情况下通知内容**只在设备本地解析**，不上传。
- 通知默认只在本机解析。仅当您在「我的 → AI 增强」中**单独打开「AI 识别通知」**并配置了模型接口时，上述应用的通知（标题与正文）才会发送到**您指定的** OpenAI 兼容服务端判断是否为真实收付款并提取金额；被判定为非收付款的场景会在本机学成「排除规则」，之后同类通知不再外发。打开「启用大模型增强」（文字填单）或「AI 资产识别」**不会**自动开启通知外发。关闭「AI 识别通知」或未配置接口时，通知完全在本地解析。所有识别结果都会先在「待确认」中等您确认，不会自动扣款、也不会静默改账。
- 您可随时在「我的 → 自动记账」中关闭自动记账，或在系统设置中撤销通知使用权。

四、应用锁与生物识别
- 若您开启应用锁，PIN 经哈希后保存在系统安全存储中，不会以明文写入本地数据库。
- 生物识别调用系统提供的本地认证接口；生物特征数据由系统管理，不会被本应用上传。

- 语音填单：在征得麦克风与系统语音识别权限后，于设备本地将语音转为文字，再走既有本地话术预填规则；识别过程使用系统语音引擎（可优先离线模型），音频与转写结果不上传 Centli 自有服务器。

五、存储、导出与卸载
- 数据默认仅存于本机 SQLite 数据库。
- 您可主动使用「导出」功能生成 JSON / Excel，并通过系统分享至您选择的目标。导出由您触发，目标由您选择。
- 卸载应用可能导致本地数据无法恢复（除非您事先自行导出）。

六、权限说明（因平台而异）
- 通知使用权（Android，可选）：用于自动记账。
- 发送通知（Android，可选）：用于「待确认」提醒；**不存在常驻监听通知**。
- 忽略电池优化（Android，可选）：仅用于被系统清理后仍能补回通知监听。
- 生物识别 / 设备凭证（可选）：用于应用锁解锁。

七、第三方组件
- 应用基于 Flutter 及开源依赖构建（如数据库、路由、分享、本地认证等）。
- 首版不集成广告 SDK，也不集成独立的分析 / 追踪 SDK。
- 各依赖的开源许可文本可在应用内「关于 → 开源许可」中查看。

八、未成年人
- 本应用面向一般记账场景。若您为未成年人，请在监护人指导下使用。

九、政策变更与联系
- 我们可能更新本政策；更新后会在应用内展示新的生效日期。
- 项目主页：https://gitee.com/ponyhch/centli
- 如有疑问，请通过上述仓库的 Issues 联系。

十、摘要
Centli 将记账数据保存在您的设备本地；可选的通知读取仅用于生成待确认账单；无云同步。请在了解上述说明后使用相关功能。

【智能填单与语音】
· 本地规则解析默认在设备上完成。
· 语音识别可能使用系统语音服务（speech_to_text）；首次尝试可能允许联网识别（onDevice:false），失败时回退到设备端识别。
· 若你在设置中开启「LLM 增强填单」并自行配置 API Key / Base URL，相关文本会发送至你指定的 OpenAI 兼容服务端；默认关闭，密钥仅存在本机安全存储。

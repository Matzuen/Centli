# Centli 产品范围（冻结）

> 更新：2026-10-17（Asia/Shanghai）· B4  
> 依据：用户明确决策（见 `docs/grokbot/BOT_TASKS_B4.md` §0）

## 产品标准

> **一款纯粹的、单一但好用的记账软件。**

判断准则：新功能必须能回答——**「它让『记一笔』更快、或让『看懂账』更准吗？」**  
答不上来 → 不做。

---

## 核心（做，且做好）

| 能力 | 说明 |
|---|---|
| 记录 | 手动记账、待确认入账 |
| 统计 | 收支统计、趋势、分类下钻 |
| 明细 | 流水列表、搜索、账户流水 |
| 资产 | 多账户、净值、**自定义资产分类** |
| 预算 | 预算设置与执行 |
| 周期记账 | 周期规则（非订阅管理） |
| 自动记账 | 通知监听解析、待确认分栏 |
| 截图 / 语音 / 文本记账 | 截图走大模型视觉；语音按住说话；文本粘贴 |
| 导入导出 | JSON / Excel |
| 回收站 | 软删除与恢复 |
| 安全 | 应用锁等 |

---

## 明确不做（永久）

| 模块 | 原因 |
|---|---|
| **订阅管理** | 用户 2026-10-17 选择整块删除；与周期记账重复 |
| **本地 OCR** | 用户裁定不必要；截图识别改走大模型视觉 |
| **商户管理** | 用户裁定「没有必要」；解析商户并入备注 |
| **心愿 / 存钱计划** | 用户裁定「没有必要」 |
| **借贷 / 报销** | 用户裁定「没有必要」 |
| 股票 / 基金行情 | 需行情后端，与「纯本地」冲突 |
| 云同步（WebDAV / Drive / iCloud） | 与「纯本地」冲突 |
| 会员 / 付费墙 | 单人自用无意义 |
| 分期还款计划 | 财务计算复杂、单人低频 |
| 物品 / 保修 | 不是记账职能 |

## 资金变动类通知的扩展方式

除收支外，非消费资金变动（还款、提现、充值等）若要支持，按下列三处同步加模板，并明确是否计入统计：

1. Dart 内置：`notification_parse.dart` → `builtinNotiTemplates()`
2. 官方 JSON：`assets/noti_templates.json`（`version` +1）
3. 原生：`NativeCaptureIngest.kt` 的 MUST / EXCLUDE 关键词

**计入统计**：默认应避免与已有消费重复计数（例：花呗还款 → `direction=repay`，默认 `includeInStat=0`）。

本批仅实现支付宝「还款」；其余类型只列扩展位，不实现。

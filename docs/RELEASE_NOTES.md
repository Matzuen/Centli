# Centli 1.4.1+7 发行说明

**版本**：`1.4.1+7`  
**产品**：Centli（厘记）— 本地优先个人记账  
**界面**：简体中文  
**日期**：2026-10-17（Asia/Shanghai）

适合粘贴到 GitHub Release、应用商店「更新说明」或安装包附注。

---

## 亮点

- **待确认更可靠**：分栏改为「待确认 / 解析失败 / 已忽略 / 已入账」严格划分，不再出现「只在全部里有数据」；花呗 / 信用卡等**还款**类通知可正确捕获（默认不计入消费统计与预算，避免与原消费重复）
- **截图记账改视觉识别**：去掉本地 OCR，账单截图交由 DeepSeek 等大模型视觉识别后填单；识别失败会显示真实错误原因，并可在智能填单里「测试连接」
- **语音按住说话**：语音记账改为微信式「按住说话、上滑取消」，识别结果仍可改后再提交
- **资产类型可自定义**：各账本可自行增删改资产分类，账户归属更清晰
- **产品更纯粹**：整块移除订阅模块；记账面板去掉币种芯片、记账模板与成员芯片

## 记账面板

- 保留支出 / 收入 / 转账类型切换与单行芯片快捷录入
- 金额键盘仍支持加减乘除（先乘除后加减）
- 已移除：币种芯片、备注旁「存为模板」与模板入口、成员芯片
- 底栏「记一笔」仍可长按进入文字 / 语音记账

## 修复与体验改进

- 待确认页分段控件在窄屏上不再溢出、各分栏数据一致
- 图片识别失败时展示服务端错误详情，便于排查配置 / 网络问题
- 智能填单展示当前模型配置，并支持一键测试连接；旧模型配置可自动迁移到 deepseek-flash
- 首页日历格行高压缩，减少上下留白
- 清理一次性脚本与过期注释；版本号与 README 变更日志单一来源守卫

## 已知限制

- 语音适合短句；**超长录音仍不适合**
- 账单截图会经所选大模型接口处理（首次使用会提示；无网或未配置时无法视觉识别）
- 历史流水的「来源」**不会自动回写补齐**（新产生的待确认 / 入账按现行逻辑展示）
- 桌面小组件目前仅 Android（MVP）；iOS 小组件未做
- 通知自动记账仍以微信 / 支付宝**支付成功与还款类**通知、CNY 场景为主
- 无云同步（本地优先）；Excel 导入为尽力而为，完整迁移请用 JSON 备份
- 已移除订阅、记账模板与成员芯片；相关历史入口不再提供

## 技术说明（可选）

- 栈：Flutter · Drift (SQLite) · Riverpod · go_router
- 本版含 B4（资产类型、视觉截图记账、按住说话、待确认分栏与还款、去订阅）与 B4-PATCH（golden 严格比对与 MaterialIcons、智能填单诊断、版本守卫）
- 构建正式包：`flutter build apk --release` → `build/app/outputs/flutter-apk/app-release.apk`

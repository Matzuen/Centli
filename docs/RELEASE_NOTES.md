# Centli 1.1.1+4 发行说明

**版本**：`1.1.1+4`  
**产品**：Centli（厘记）— 本地优先个人记账  
**界面**：简体中文  

适合粘贴到 GitHub Release、应用商店「更新说明」或安装包附注。

---

## 亮点

- **首页一眼看清**：摘要与净资产折线，日历格直接显示当日收支，每日趋势折线更易读
- **记账更快更准**：传统记账面板保留芯片快捷行；金额键盘支持加减乘除（先乘除后加减）
- **文字 / 语音独立面板**：底栏「记一笔」可长按进入文字记账或语音记账；传统面板专注手动录入
- **账单标签**：可为流水添加标签，支持列表展示、详情编辑、搜索与导入导出
- **资产更靠谱**：多币种账户按汇率折算后合计净资产；归档态仍保留净资产相关展示
- **待确认更清晰**：自动记账来源用通俗文案展示，摘要可折叠，页面更清爽
- **深色 / 顶栏更舒服**：修复浅色顶栏异常底色与深色模式下分段控件对比度等问题

## 修复与体验改进

- 折线 X 轴日期标签重叠：按宽度稀疏取样并保留首末点
- 图标网格溢出等布局问题
- 文案与数据不一致的标签修正；统一常用词表
- 统计页底距与分段控件位置
- 概览日历与区间状态解耦，减少误触干扰
- 删除确认等提示去掉内部术语，更贴近日常用语
- 暗色记账键盘配色统一

## 已知限制

- 语音记账适合短句，**长录音暂不支持**
- 历史流水的「来源」**不会自动回写补齐**（新产生的待确认 / 入账按现行逻辑展示）
- 桌面小组件目前仅 Android（MVP）；iOS 小组件未做
- 通知自动记账仍以微信 / 支付宝**支付成功类**通知、CNY 场景为主
- 无云同步（本地优先）；Excel 导入为尽力而为，完整迁移请用 JSON 备份

## 技术说明（可选）

- 栈：Flutter · Drift (SQLite) · Riverpod · go_router
- JSON 备份当前 `schema_version: 4`（含账单标签等）
- 构建正式包：`flutter build apk --release` → `build/app/outputs/flutter-apk/app-release.apk`

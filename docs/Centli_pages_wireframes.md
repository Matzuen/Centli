# Centli（厘记）— 页面清单 + 线框说明

> 产品：**Centli：厘清每一笔账单**  
> 栈：Flutter · 通知 + 待确认 · 常见币种  
> 范围：P0～P2 首版；标注 `[P3]` 的仅占位，首版可不做。

---

```
┌─────────────────────────────┐

├─────┬─────┬─────┬─────┬─────┤

## 1. 启动与引导

### 1.1 Splash `[P0]`
- 居中 Logo + 文案「Centli · 厘清每一笔账单」
- 初始化 DB / 读设置后进入首页或引导

### 1.2 首次引导（可跳过）`[P0～P1]`
三页横向滑动：

1. **记一笔** — 示意计算器面板  
2. **通知待确认** — 示意「支付通知 → 待确认卡片 → 一键入账」  
3. **开启通知权限** — 主按钮「去开启」；次按钮「稍后再说」

完成后写 `onboarding_done=true`。

### 1.3 应用锁（可选）`[P2]`
- 开启后冷启动 / 回前台需生物识别或 PIN
- 失败可「用 PIN」；无系统生物识别则仅 PIN

## 2. 首页 `/home`

### 线框

```
┌──────────────────────────────┐
│ Centli          [眼睛] [账本▼]│
│ 2026年10月                   │
│ ┌──────────┐ ┌──────────┐   │
│ │ 支出 ¥x  │ │ 收入 ¥x  │   │
│ └──────────┘ └──────────┘   │
│ ┌ 待确认 (3) ─────────── › ┐ │
│ │ 支付宝 · ¥28.5 · 猜「餐饮」│ │
│ │ 微信   · ¥12   · 待选分类 │ │
│ └──────────────────────────┘ │
│ 最近                          │
│ ● 餐饮  午饭    -¥28.5  12:01 │
│ ● 交通  地铁    -¥4     09:10 │
│ ● 转账  微信→招行 …          │
└──────────────────────────────┘
```

### 交互
| 元素 | 行为 |
|---|---|
| 眼睛 | 切换藏金额 |
| 账本▼ | 切换账本（首版可只有默认账本，入口先留） |
| 月标题 | 左右滑或点选月份，概览与列表跟随 |
| 待确认条 | 进 `/pending`；单条可左滑「忽略」 |
| 账单行 | 进账单详情；左滑删除（二次确认） |
| 下拉 | 刷新（并唤醒通知侧轮询缓存） |

### 空态
- 无账单：插画 +「点中间 ＋ 记第一笔」  
- 无待确认：整块待确认区隐藏

## 3. 待确认列表 `/pending`  `[P1]`

```
┌──────────────────────────────┐
│ ← 待确认                      │
│ [全部] [仅失败解析]           │
│ ┌──────────────────────────┐ │
│ │ 今天 14:32  支付宝        │ │
│ │ ¥28.50                    │ │
│ │ 商户：某餐厅               │ │
│ │ 分类：[餐饮 ▼] 账户:[支付宝▼]│
│ │ [忽略]              [入账] │ │
│ └──────────────────────────┘ │
│ …更多卡片…                   │
└──────────────────────────────┘
```

### 交互
- **入账**：写入流水，更新商户规则，移出队列  
- **忽略**：status=ignored，可在「设置 → 已忽略」找回（可 P2）  
- 解析失败：金额可点按编辑；商户可改  
- 批量：右上「全部忽略」谨慎放，需确认框

## 4. 记账面板（Modal）`/ledger/new`  `[P0]`

半屏 / 近全屏底部面板，拇指优先。

```
┌──────────────────────────────┐
│ 支出 │ 收入 │ 转账     [×]   │
│          ¥ 0                 │
│ 备注 ________________        │
│ [餐饮][交通][日用][… 更多]   │
│ 账户 支付宝 ▼   今天 14:32 ▼ │
│ ┌───┬───┬───┬───┐           │
│ │ 1 │ 2 │ 3 │ ⌫ │           │
│ │ 4 │ 5 │ 6 │ + │           │
│ │ 7 │ 8 │ 9 │ - │           │
│ │ . │ 0 │00 │ ✓ │           │
│ └───┴───┴───┴───┘           │
└──────────────────────────────┘
```

### 规则
- 默认「支出」；分类只显示对应 kind  
- **转账**：选转出账户 / 转入账户；同币种只填金额；跨币种多一行「对方金额或汇率」  
- ✓ 校验：金额>0、分类（转账除外）、账户齐全 → 落库关面板  
- 再记一笔：✓ 长按或设置项「保存后不清空」（可后做）

┌──────────────────────────────┐

│ 时间  2026-10-13 12:01        │
│ 来源  通知自动 / 手工         │

```

- **改**：回到记账面板编辑态  
- **删**：确认后软删或硬删（首版硬删即可）  
- 转账单：展示两侧账户与汇率

## 6. 统计 `/stats`  `[P2]`

```
┌──────────────────────────────┐
│ ‹ 2026年10月 ›   本位币 CNY  │
│ 支出合计 / 收入合计           │
│ [折线：每日支出]              │
│ [饼/环：分类占比]             │
│ 分类列表  餐饮 32%  ¥xxx   › │
└──────────────────────────────┘
```

- 点父分类 → 筛选后的账单列表（可复用首页列表组件）  
- 多币种：按本位币折算；无汇率的原币流水角标「未折算」  
- 空月：友好空态，不画空图

## 7. 资产 `/assets`  `[P0]`

```
┌──────────────────────────────┐
│ 资产              [+ 账户]   │
│ 净额（本位币）¥xx,xxx        │
│ CNY                          │
│  支付宝      ¥1,200       › │
│  招商银行    ¥8,000       › │
│ USD                          │
│  美金现金    $200         › │
└──────────────────────────────┘
```

### 账户详情 `/assets/:id`
- 余额、币种、期初、流水列表（按月）  
- 操作：编辑账户、调整余额（记一笔「余额校正」或改期初，方案选一种写进设置说明）、归档

### 新建/编辑账户
- 名称、币种（预置 CNY/USD/JPY/TWD/HKD/EUR）、类型（现金/银行卡/电子钱包/其他）、期初余额

## 8. 我的 `/me`  `[P0 骨架 + P1/P2 项]`

| 分组 | 项 | 阶段 |
|---|---|---|
| 账本 | 默认账本、本位币 | P0 |
| 分类 | 支出/收入分类管理 | P0 |
| 预算 | 月度总额 / 分类预算 | P3 |
| 自动记账 | 总开关、通知权限状态、测试解析 | P1 |
| 安全 | 应用锁、藏金额默认 | P2 |
| 数据 | 导出 JSON/Excel、（导入 P3） | P2 |
| 关于 | 版本、开源许可、隐私说明链接 | P0 |

### 分类管理 `/me/categories`
- Tab：支出 / 收入  
- 一级列表，右进二级；排序拖拽可后置  
- 预置一套常用分类，可改名不可删「有流水的分类」（改归档）

### 自动记账设置 `/me/auto`
```
[x] 启用通知记账
通知权限：已开启 / 去开启
监听应用：支付宝、微信（可扩展清单）
[清理待确认] [查看解析模板版本]
```

# Centli 真机验证清单（B3 / T5-2）

每项：操作 → 期望 → 失败含义。

## 1. 通知监听：后台 vs 被杀

1. 打开 Centli，授权通知监听。  
2. **App 在后台**：用支付宝/微信发一条带金额的支付成功通知。  
3. 期望：进入「待确认」。  
4. **强制停止 App** 后再发一条。  
5. 期望：仍进入待确认（若失败 → 杀进程后原生监听未恢复，B2 残留风险）。

## 2. 自定义规则

1. 设置 → 自动记账 → 规则 → 添加非支付宝/微信包名 + 关键词。  
2. 杀 App 后用该应用发匹配通知。  
3. 期望：待确认出现。失败 → 用户规则未进原生过滤。

## 3. 收支方向

1. 触发微信「收款到账 / 你领取了…红包 / 你收到一个红包」类文案。  
2. 期望：待确认方向为**收入**。失败 → T0 回归或模板被排除。

## 4. 退款

1. 触发「退款成功」类通知。  
2. 期望：类型退款；统计**不增加收入**。失败 → 退款口径错误。

## 5. 周期记账

1. 我的 → 周期记账 → 新建「每天」小额支出，起始日选昨天。  
2. 保存后重启 App（或隔天打开）。  
3. 期望：流水出现且 `happenAt` 为对应日期；再启动**不重复**。失败 → catch-up/幂等失效。

## 6. 主题浅/暗

1. 系统浅色/暗色下打开记一笔、待确认、周期、订阅页。  
2. 期望：无裁切、键盘配色可读。失败 → 暗色 helper 未覆盖。

## 7. 输入法

1. 记一笔备注框聚焦。  
2. 期望：面板上移不被键盘遮死。失败 → viewInsets 处理问题。

## 8. 备份往返

1. 导出 JSON → 清空/新装 → 导入。  
2. 期望：金额、标签、成员、预算开关一致；周期/订阅表在 schema≥6/7 设备上存在。失败 → 导出未含新表（已知：若导出服务未扩表则需后续工单）。

## 9. 图标

1. 安装 debug APK，查看桌面图标与圆形图标。  
2. 期望：新 logo，无双重严重裁边。失败 → 自适应前景缩放问题。

# Centli（厘记）

本地优先的个人记账应用：**厘清资产，安心记账**。界面为**绿紫渐变**风格，文案为**简体中文**（当前不提供多语言切换）。

- Flutter · Drift (SQLite) · Riverpod · go_router
- 当前版本：`2.1.2+44`（见 `pubspec.yaml`；**界面只展示 `2.1.2`**，构建号留给商店 / 打包）
- 币种展示：`CNY · 人民币`

## 简介

Centli 把记账本、资产账户、分类与流水放在本机 SQLite，不做云同步。底部导航固定五栏：**首页 / 统计 / 记账 / 资产 / 我的**（中间「记账」打开记账面板，而非悬浮按钮）。首页提供摘要与净资产走势，记账支持芯片快捷输入、四则运算金额，以及独立的文字快速记账面板（长按底栏「记一笔」）。

## 功能

| 模块 | 说明 |
|------|------|
| 导航 | 固定五栏：首页、统计、记账、资产、我的；底栏「记一笔」支持长按进入文字快速记账（语音已移除） |
| 首页 | 记账本上下文；摘要卡（净资产 + 资产 / 负债两列 + 月度预算条）；净资产折线（按住看某天）；待确认轮播卡片可就地入账；日历格展示当日收支；日历页「每日收支」单图（每天一个点，盈亏分色） |
| 流水记账 | 支出 / 收入 / 转账（退款记收入 +「退款」标签/备注，不再单独成类型）；传统记账面板（芯片行 + 分类选择，金额键盘支持加减乘除）；独立文字快速记账面板（记住上次资产账户 / 分类，备注自动带出上次分类）；账单标签；软删除进回收站可恢复 |

| 预算 | 月度总额 / 分类限额（本位币） |
| 待确认 · 自动记账 | Android 监听**微信 / 支付宝 / 自定义包名**交易类通知 → 悬浮窗（可选**资产账户**与分类）或待确认入账；通知栏可「确认 / 详情 / 忽略」；「最近忽略」可一键加入监听并建规则；控制中心「自动记账」快捷开关；**无常驻通知**（系统重绑 + 周期任务补回）；宁多抓不漏记 |

| 记账记忆 | 再次记一笔时沿用上次的资产账户 / 分类；备注（如「午饭」）会自动带出上次用的分类；账单详情可「照着这笔再记一笔」 |

## 账单详情与逐项编辑

从首页、搜索、资产账户明细或统计下钻点开任一笔账单，进入**账单详情**：

- 顶栏只有 **保存** 与 **删除**（不再有「编辑」图标）。「保存」仅在有待提交改动时可点，保存后提示「已保存」并变灰。
- 以下每一项都可**单独点击修改**，选择类改动**即时落库**（切页面 / 返回不会丢）：

  | 项目 | 交互 |
  |------|------|
  | 金额（顶部大字） | 弹输入框，支持 `12+8` 之类算式；点「保存」才提交 |
  | 资产账户 / 转入资产账户 | 资产账户选择面板（包含已归档资产账户，历史账单可改回） |
  | 分类 | 分类选择面板（按当前收支方向过滤） |
  | 类型 | 「改类型」：支出 / 收入 / 转账；改方向后分类自动校验 |
  | 时间 | 日期 + 时间 |
  | 标签 | 标签编辑（最多 5 个，带常用标签建议）；无标签时留空 |
  | 备注 | 文本弹窗 |
  | 计入统计 / 计入预算 | 开关，立即生效 |

- 逐项修改**只更新被改动的字段**，不会覆盖「来源」、通知去重键、汇率等原样保留的字段。

## 通知识别规则（模板 v11 · 标题门控 + 正文判收支）

App 打包 **2 条**内置规则（微信 / 支付宝各一条），`assets/noti_templates.json` 与代码内建模板逐条一致（有测试守卫）。无独立官网规则源。

两段逻辑：

1. **标题门控（是否抓取）**：标题含 支付 / 收款 / 退款 / 转账 / 还款 等交易词才进入解析；**正文不参与是否抓取**。提醒类标题（待还、还款提醒、验证码、朋友圈等）仍排除。
2. **正文判收支**：命中后再看正文里的方向词——退款 / 到账 / 收款 / 转账成功等 → 收入；支付 / 还款 / 裸转账等 → 支出；正文没有方向词则回退标题，再没有则默认支出。退款 / 还款另打标签（不是独立账单类型）。

金额仍从正文解析（须带 `¥` 等或「元」回退）。设计取向是**宁可多抓、不漏记**。

本机覆盖文件版本偏低时，请到 **我的 → 自动记账 → 识别规则 → 检查更新**（写入当前 v11），或菜单 **恢复内置规则**。

## 备份与还原

- **推荐**：`我的 → 导出` 勾选 JSON，再在 `我的 → 导入` 还原。格式 `centli-export`，`export_version: 1`，当前 `schema_version: 4`（含预算与账单标签等）。
- **Excel**：适合表格查看；导入为尽力而为——**不含** `fx_rates` / `settings` 工作表，缺省字段会补默认值。无损迁移请用 JSON。
- 还原只清空**备份中该记账本**下的资产账户 / 分类 / 流水 / 待确认 / 商户规则 / 预算后写入；其它记账本不受影响。JSON 还会整体替换汇率缓存；通知识别规则（我的规则）不在备份内。资产锁 PIN 留在本机安全存储，不会被备份覆盖。
- 全部为**本地**导入 / 导出，无云备份。

## 隐私

数据默认仅存本机 SQLite。通知监听用于解析**支付宝 / 微信以及你主动加入监听的应用**的交易类通知并写入「待确认」；默认不发送通知原文到任何服务器；只有你自己在「AI 增强」里**单独打开「AI 识别通知」**并配置接口后，监听应用的通知才会先发给你指定的模型判断（判为非收付款的会学成本地「排除规则」，判为收付款的会学成「软件名-支出/收入」规则，之后同场景通知直接本机处理、不再外发也不再调用模型；关闭该开关即恢复纯本地解析）。详见应用内「关于 → 隐私政策」与 `assets/legal/privacy_zh.txt`。
